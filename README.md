# 2級土木施工管理士補 スマホ学習アプリ（試作版）

## 入っている機能
- 260件の全文検索
- 5科目で絞り込み
- A/B/Cランクで絞り込み
- 未学習／復習／習得で絞り込み
- スマホ向けカード表示
- 学習状況を端末内に保存（localStorage）
- PWAオフラインキャッシュ対応

## PCでまず試す
`index.html` をダブルクリックすると、検索・絞り込み・学習状況保存を試せます。
（ブラウザーによっては file:// で保存機能に制限があるため、普段使いはHTTPS公開後がおすすめです。）

## スマホのホーム画面アプリとして使う
PWAのインストールと完全なオフライン利用には、最初の1回だけHTTPSで配信する必要があります。
GitHub Pages / Cloudflare Pages / Firebase Hosting など無料枠のあるHTTPS公開先が使えます。
公開後にスマホで開き、ホーム画面に追加します。その後はキャッシュ済みデータをオフラインで検索できます。

## データ更新
元データは `data.js` に260件すべて埋め込んであります。
将来Excelを更新したときは、この `data.js` を再生成すればアプリ本体を作り直さず更新できます。
